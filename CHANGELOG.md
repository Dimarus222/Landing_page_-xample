# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), версионирование — [SemVer](https://semver.org/lang/ru/).
Каждое значимое изменение проекта фиксируется здесь — см. правило в `CLAUDE.md`, раздел 8.

## [4.1.0] — 2026-08-01

### Добавлено
- Встроенная интерактивная IDE для практики (`ideBlock()` в `app.js`): режим `web` (живой HTML/CSS/JS-редактор
  с sandboxed-превью, офлайн) и режим `exec` (выполнение Python/др. языков через публичный сервис Piston,
  нужен интернет). Примеры использования — уроки 5.2 и 4.3.
- 12 новых полноценных уроков: ОС/сети 3.5–3.8, Криптография 4.5–4.8, WebSec 5.5–5.8.
- `text-align: justify` для текста уроков во всех темах.

### Исправлено
- Кнопка «Отметить пройденным» теперь мгновенно меняет цвет/иконку без перезагрузки урока.
- Кнопка «Начать →» на карте обучения и ссылка «Главная» в хлебных крошках — раньше меняли только URL-хеш
  без реального перехода (в проекте нет обработчика `hashchange`), из-за чего клик визуально не срабатывал.
  Теперь обе явно вызывают `loadLesson()`/`renderRoadmap()`.
- `sw.js`: стратегия кеша изменена с cache-first на network-first, чтобы новые деплои подхватывались автоматически.

### Изменено
- `app.js` теперь подключается в `index.html` раньше `data-*.js` — требуется, чтобы `ideBlock()` был доступен
  в момент загрузки данных уроков.

## [4.0.0] — 2026-08-01 — «Kernel»

### Изменено
- Полный ребрендинг **SecOpticon → KERNEL**: название, favicon, PWA-манифест, заголовки, метатеги.
- Кибернетический редизайн: неоновая цветовая палитра, сетка на фоне, скан-линии, свечения (glow) на активных
  элементах, моноширинный шрифт для брендовых элементов.
- Репозиторий переведён на плоскую структуру файлов (без подпапок `css/`, `js/`, `js/data/`) для простоты
  загрузки на GitHub и деплоя.
- Прогресс пользователей (`localStorage`) автоматически переносится со старых ключей `secopticon_*` на новые
  `kernel_*` при первом заходе — никто ничего не теряет.
- Убран нерабочий `.github/workflows/static.yml` и некорректный файл `CNAME` — деплой теперь через встроенный
  GitHub Pages без Actions (см. README, раздел «Деплой»).

### Добавлено
- Три темы оформления: `dark` (кибер), `matrix` (терминальная), `sepia` (светлая) — переключение по кругу.
- Командная палитра быстрого поиска по урокам (`Ctrl/⌘ + K`).
- Автособираемый глоссарий терминов (`renderGlossary()`) — собирает все `<span class="definition">` по курсу.
- Система достижений (9 достижений «из коробки», легко расширяется — см. `CLAUDE.md`, раздел 2).
- Счётчик серии дней подряд (streak) на сайдбаре.
- Оценка времени чтения урока.
- Экран «Продолжить обучение» на главной, если у пользователя уже есть прогресс.
- Заглушка профиля/авторизации с понятным сообщением «скоро» вместо отсутствующей кнопки — прозрачно
  сообщает пользователю статус фичи.
- Семестр 3 «ОС и сети» расширен с 1 до 4 уроков (архитектура ОС и процессы, память и файловые системы,
  стек TCP/IP, DNS/TLS и анализ трафика).
- Семестр 4 «Криптография» расширен с 1 до 4 уроков (симметричное шифрование, асимметричная криптография и
  PKI, хеш-функции/HMAC/подписи, постквантовая криптография).
- Семестр 5 «Безопасность приложений» расширен с 1 до 4 уроков (SQL-инъекции, XSS/CSRF, OWASP Top 10/SSRF,
  сетевая защита периметра).

### Исправлено
- **Критический баг:** семестр 2 («Языки программирования и эксплуатация») не регистрировал себя в реестре
  семестров и был полностью невидим на сайте. Исправлено.
- `sw.js` кешировал неполный список файлов (не включал материалы права и языков программирования) — список
  приведён в соответствие с реальной структурой сайта, версия кеша увеличена.
