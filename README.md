# KERNEL

> Теоретическое ядро компьютерной безопасности. Бесплатный, полностью статический учебный сайт по специалитету **10.05.01 «Компьютерная безопасность»**: право, математика, C/ASM и эксплуатация, ОС и сети, криптография, безопасность приложений.

Живёт на GitHub Pages, работает офлайн (PWA), не требует сервера и не тратит ваш бюджет.

## Возможности

- 📚 Полный теоретический курс, разбитый на семестры и уроки, с блоками теории, примеров, предупреждений и источников
- 🗺️ Карта обучения с прогрессом по каждому семестру
- 🔍 Поиск по урокам + быстрая командная палитра (`Ctrl/⌘ + K`)
- 📖 Автособираемый глоссарий терминов из размеченного контента
- ⭐ Избранное, ✅ отметки о прохождении, 📝 личные заметки к урокам — всё хранится локально в браузере
- 🔥 Серия дней подряд и 🏆 система достижений
- ⏱️ Оценка времени чтения урока
- 🎨 Три темы оформления: тёмная (кибер), матрица (терминальная), сепия (светлая, для долгого чтения)
- 📴 Полностью работает офлайн после первого захода (Service Worker)
- 🖨️ Экспорт урока в PDF, экспорт/импорт прогресса в JSON-файл
- ⌨️ Горячие клавиши (`←/→` — соседние уроки, `R` — случайный, `?` — шпаргалка)

Авторизация и облачная синхронизация прогресса **пока не реализованы** — это следующий шаг, см. раздел «Roadmap» и `CLAUDE.md`.

## Технологии

Только фронтенд: HTML + CSS + vanilla JavaScript. Никакого бэкенда, базы данных или сборки — то, что нужно, чтобы бесплатно жить на GitHub Pages. Из внешнего — только CDN для иконок (Font Awesome) и подсветки кода (highlight.js).

## Структура репозитория

Все файлы лежат в корне репозитория без вложенных папок — так проще смотреть, редактировать и деплоить:

```
index.html         — разметка страницы
style.css          — все стили и три темы оформления
app.js             — вся логика: рендер уроков, поиск, темы, достижения и т.д.
data-law.js        — семестр 0: право (НПБ)
data-math.js       — семестр 1: математика
data-cs.js         — семестр 2: языки программирования и эксплуатация
data-os-net.js     — семестр 3: ОС и сети
data-crypto.js     — семестр 4: криптография
data-websec.js     — семестр 5: безопасность приложений
manifest.json      — PWA-манифест
sw.js              — Service Worker (офлайн-кеш)
README.md          — этот файл
CLAUDE.md          — инструкция для ИИ-агента по доработке и ведению документации
CHANGELOG.md        — история изменений
```

## Как добавить/изменить контент

Каждый файл `data-*.js` регистрирует один семестр в `window.__KERNEL_SEMESTERS`. Формат урока и правила стилизации подробно описаны в `CLAUDE.md` — это основной документ для того, чтобы дальше развивать сайт (в том числе с помощью нейросети/ИИ-агента).

## Деплой на GitHub Pages (бесплатно, без Actions)

1. Загрузите все файлы из этого архива в корень вашего репозитория (важно: без вложенной папки).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через минуту сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/<репозиторий>/`.

Если нужен собственный домен — добавьте файл `CNAME` с одной строкой (вашим доменом) и настройте DNS-запись у регистратора домена (обычно `CNAME`-запись на `<ваш-логин>.github.io`). Раньше в проекте лежал файл `CNAME` с некорректным значением — он удалён; при необходимости создайте новый со своим реальным доменом.

## Локальный запуск

Сайт статический, поэтому достаточно любого локального веб-сервера (открывать `index.html` напрямую через `file://` не будет работать из-за ограничений Service Worker и `fetch`):

```bash
# Python 3
python3 -m http.server 8080
# или Node.js
npx serve .
```

Затем откройте `http://localhost:8080`.
